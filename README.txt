BUSINESSBUDDY — PACCHETTO PRONTO PER GITHUB + RENDER

FILE INCLUSI
- index.html: applicazione web
- manifest.webmanifest, sw.js, icon.svg: installazione PWA e cache offline
- render.yaml: configurazione Render Static Site

PUBBLICAZIONE (SENZA TERMINALE)
1. Estrai questa ZIP sul computer, in una cartella chiamata businessbuddy.
2. Apri https://github.com/new e crea un repository chiamato businessbuddy.
3. Seleziona Add file > Upload files e carica i FILE contenuti nella cartella estratta (index.html, manifest.webmanifest, sw.js, icon.svg, render.yaml e README.txt), non la cartella esterna e non la ZIP.
4. Premi Commit changes.
5. Apri https://dashboard.render.com/ e scegli New > Static Site.
6. Collega GitHub, seleziona il repository businessbuddy e avvia la creazione.
7. Se Render chiede i dettagli: Build Command lascialo vuoto; Publish Directory inserisci . (punto). In alternativa, usa il Blueprint se Render rileva render.yaml.
8. Attendi il deploy e apri l'URL .onrender.com.

IMPORTANTE
Questa versione è un prototipo dimostrativo. I dati sono salvati localmente nel browser/dispositivo e NON si sincronizzano tra dispositivi. Non contiene account, database online, prenotazioni pubbliche, notifiche email/WhatsApp o pagamenti/abbonamenti. Il prezzo obiettivo di 7,99 €/mese non significa che il pagamento sia attivo. Prima di vendere l'app servono backend/database, autenticazione, integrazione pagamenti e verifiche di sicurezza e privacy. Non inserire dati personali reali dei clienti.

Se il sito non si apre o dà errore, controlla che index.html sia nella radice del repository e che Publish Directory sia .
